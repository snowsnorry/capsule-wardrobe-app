# repo-orientation

Use this skill when starting work in this repository.

## Steps
1. Read root `AGENTS.md`
2. Read `docs/repo_map.md`
3. Identify whether the task belongs to `client` or `server`
4. Read the nearest tests before changing code
5. Propose the smallest safe file set to edit

## Output format
Always summarize:
- owning workspace
- likely files to inspect
- validation command to run
